# DeepvoiceGAN
본 프로젝트는 GAN(Generative Adversarial Network) 을 활용하여 실제 음성과 딥보이스(가짜 음성)를 구분하고, 이를 바탕으로 보이스피싱 여부를 판별하는 인공지능 모델 개발을 목표로 진행되었다. 최근 보이스피싱 범죄에서 AI 기반 음성 복제 기술(딥보이스)이 악용되는 사례가 증가함에 따라, 음성 데이터의 진위를 판별할 수 있는 탐지 시스템의 필요성을 느껴 연구를 시작하였다.  프로젝트는 실제 음성과 생성 음성 데이터를 직접 수집하고, 음성 신호 처리 기법과 GAN 기반 생성 모델을 결합하여 음성의 패턴 차이를 학습하는 방식으로 설계되었다.
